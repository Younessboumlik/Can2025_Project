# 🚀 Quick Start Guide

Get started with CAN 2025 Predictor in 5 minutes!

## ⚡ Installation (2 minutes)

```bash
# Clone the repository
git clone https://github.com/Younessboumlik/Can2025_Project.git
cd Can2025_Project

# Install dependencies
pip install -r requirements.txt

# Run the app
streamlit run app.py
```

Open your browser to `http://localhost:8501`

## 🎯 Your First Prediction (1 minute)

1. **Navigate to "🎯 Match Unique" tab**
2. **Select two teams** from the dropdowns
3. **Click "🔮 Prédire"**
4. **View results**: Win probabilities and expected score

Example: Morocco vs Egypt
- Result might show: Morocco 45%, Draw 25%, Egypt 30%
- Score: Morocco 1.8 - 1.4 Egypt

## 🏆 Simulate the Tournament (2 minutes)

1. **Go to "🎲 Simulation Unique" tab**
2. **Click "🚀 Simuler le Tournoi"**
3. **Watch the tournament unfold**:
   - Group stage matches
   - Knockout rounds
   - Champion crowned! 🎉

## 📊 Statistical Analysis (Optional)

**For deeper insights**:

1. **Go to "📊 Monte Carlo" tab**
2. **Set simulations to 1000**
3. **Click "🚀 Lancer la simulation"**
4. **View probabilities** for each team

Result shows:
- Champion percentage
- Probability to reach each stage
- Top 10 contenders

## 🔍 Explore Team Stats

1. **Go to "📈 Stats Équipes" tab**
2. **Select a team**
3. **View comprehensive statistics**:
   - FIFA ranking
   - Market value
   - Offensive/Defensive form
   - Momentum
